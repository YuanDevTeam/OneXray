## 功能

- 支持 iPhone、iPad、Mac、Android、Windows 和 Linux，提供浅色 / 深色主题及五种界面语言。
- 导入分享链接、Xray JSON 和订阅，支持手动分组与服务器测速。
- 智能路由、自定义路由、Raw JSON 和服务商完整配置，包括 Remnawave 订阅。
- 无需账户，不含广告、分析或跟踪。[隐私政策](https://onexray.com/zh/docs/privacy/)。

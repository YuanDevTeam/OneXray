## Возможности

- iPhone, iPad, Mac, Android, Windows и Linux, светлая и тёмная темы и пять языков интерфейса.
- Импорт ссылок, Xray JSON и подписок, ручные группы и проверка серверов.
- Умная и пользовательская маршрутизация, Raw JSON и полные конфигурации провайдеров, включая Remnawave.
- Без учётных записей, рекламы, аналитики и отслеживания. [Политика конфиденциальности](https://onexray.com/ru/docs/privacy/).

[GPL-3.0](../LICENSE) с [исключением для VPN-провайдеров](../LICENSE-EXCEPTION). Исключение разрешает специализированные клиенты с закрытым исходным кодом только для собственного VPN-сервиса провайдера, без универсальной поддержки сторонних конфигураций и подписок. В интерфейсе должны быть видимая ссылка на проект и указание, что клиент основан на OneXray. Полные условия и обязательства по сторонним лицензиям приведены в тексте исключения.

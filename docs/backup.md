# 连接配置备份

备份页面位于设置的数据区；连接/服务器空状态在当前 Tab 打开同一页面，不自动绑定目标或执行恢复。
仅支持平台显示入口。App 只绑定一个目标，备份和恢复均使用该文件；创建时默认名为 `OneXray-backup.json`。
不提供版本列表、双向同步或云账号登录。
文件未加密，包含节点凭据、订阅 URL、Age 私钥和 HWID；Base64 不保密。
绑定时先探测内容：空文件直接写入首份备份；有内容时选择恢复或覆盖，取消不改变原来的绑定或文件。
后续备份覆盖同一文件，不设单独的“允许向此位置备份”状态。
旧设置中明确未确认的目标按未绑定处理，重新选择后走相同的内容探测与恢复/覆盖流程。
绑定后，位置操作只显示解除绑定和切换目标；Apple 在 iCloud 与本地文件间切换，
切换至文件时再选择已有文件或创建文件。取消切换保留原绑定。

## 平台存储

| 平台 | 目标与边界 |
| --- | --- |
| iOS / macOS / macOS SE | 首选入口为 iCloud Drive，使用原有容器中的 `Documents/OneXray-backup.json`；也可绑定用户选择的文件，两者共用备份、恢复和自动周期 |
| Android | SAF 单文档 URI，`saf_stream` 内容读写；Pigeon 只选择/创建、检查持久读写授权和释放旧目标授权；展示提供商实际文件名 |
| Windows EXE / ZIP / MSIX | 用户选择的 OneDrive 同步目录，普通文件读取与替换；不接 OAuth/Graph、不要求包身份 |

Apple 文件目标复用 `BackupTarget`、`BackupSettings` 与 `BackupStorage`，由原生选择器取得 bookmark，
在本机保存并于每次访问时解析、开启和释放授权；协调读写在工作队列执行，不在主线程等待文件提供商。
每次文件选择创建独立的候选标识，确认前保留原 bookmark；取消释放候选，确认后释放旧目标。
绑定标识在文件移动和替换写入时保持稳定，访问时更新对应 bookmark。
iOS 创建时选择保存目录，绑定其中的一份文件；原生创建不会先清空同名文件。
原生选择/创建阶段不写入备份内容；候选文件通过内容探测和必要选择后才保存绑定，由备份服务写入或恢复。
访问失败保留绑定和页面错误，用户可重新选择；解绑释放对应 bookmark，不删除文件。
原有 iCloud 目标及其标识保持可用，继续由 `icloud_storage_plus` 协调读写，不通过用户文件适配器。
用户文件采用原位访问，不导入 App 缓存。iOS 声明 `LSSupportsOpeningDocumentsInPlace`，通过“文件”选择保存目录；
macOS 通过系统打开/保存面板选择。
应选 App 私有目录及共享数据目录以外的位置，避免文件随卸载删除。卸载后绑定与 bookmark 会丢失，重新安装后重新选择原文件即可。

内容探测只读取元数据或首字节；读取失败不视为空文件，也不会覆盖。恢复时才完整读取、验证并展示现有预览确认。
覆盖选择不解析旧内容，可替换损坏或超过恢复大小限制的文件。选择恢复、取消恢复或校验失败期间，不会让自动备份写入候选文件。
绑定时选择恢复，先验证文件并保存新绑定，再替换连接资产；保存绑定失败不执行恢复，恢复失败回退原绑定。

Linux 不提供备份。解绑或清理 App 数据不删除云文件，更换目标释放旧文件授权并重置本机时间记录。
写入成功只表示本地容器/提供商接受内容，不表示云同步完成。
Apple/Windows 使用替换写入；Android 固定 URI 覆盖、不先删旧文档，但提供商原子性不保证，中断可能损坏旧文件。

## 协议 v1

UTF-8 JSON 的 `format=onexray-backup`、`version=1`、`createdAt` 为 Unix 毫秒；
`coreConfigs/subscriptions/routingProfiles/smartRouting/geoData` 为必要分区，缺失列表不同于空列表。
字段唯一来源是 [备份模型](../lib/core/backup/model.dart)，旧 ZIP v3/v4 不导入、不转换。
根对象及各分区忽略未知字段，重新导出时只输出当前支持的字段；格式、版本、必要字段和已知字段类型仍需有效。

可选 `platformSettings` 按 `ios`、`macos`、`android`、`windows`、`linux` 区分。
每次备份仅写当前平台的可迁移 VPN 设置；恢复只读取并校验当前平台键，其它平台分区即使格式不兼容也不影响通用资产恢复。
iOS 与 macOS 独立匹配，macOS SE 使用 `macos`；Windows 各分发使用 `windows`。
这不增加 Linux 的文件备份入口，平台存储支持仍以上表为准。

- 分区保存 IPv6、隧道 DNS、服务器拨号、LAN 共享和日志偏好，并仅包含当前系统的 Android、Apple 或 Windows 策略。
  Android 同时保存访问模式、包含与排除两份应用包名列表；未安装包名保留，沿用界面提示及原生连接时的处理。
- 平台策略复用现有解析和校验，忽略未知字段；匹配分区错误在恢复预览时报告，不停止 VPN、不写入资产。
  旧 v1 缺分区、没有当前平台键或未提供某项设置时，保留对应本机值；其它平台草稿不改变。
- 物理出口网卡名称、系统权限、API/Android 自动化授权、App 偏好及备份目标继续留在本机，不随平台分区恢复。

- 保存本地（subId=0）outbound 与全部 Raw，包括超过新增三份上限的旧 Raw；
  手动分组（含空组）、节点归属和手动顺序作为连接资产保存，分组使用文件内部 key，不保存数据库 ID。
  恢复时重新映射分组与节点；旧 v1 缺少这些可选字段时归入未分组，保持原列表次序。
  保存订阅来源的 panel/mode、可选 userAgent、原 Age 密钥对及关闭发送时仍存在的 HWID，
  排除订阅完整配置及普通派生缓存、本地修改、更新时间与套餐缓存。
  旧备份缺 panel/mode 时恢复 generic/appManaged；显式未知值仍拒绝，未知字段容忍不放宽已知枚举。
  缺 userAgent 时保留为空，下载使用恢复设备统一的订阅默认 UA，与面板类型无关；自定义 UA 按单行 ASCII 文本验证。
- 常规/高级路由保留类型、名称及原文，共用名称唯一和三份上限；
  包含 [Fragment 辅助出站及其参数](xray-configuration.md#fragment)。
  Smart 显式保存连接设置（含 Fragment 开关、可选 dns/sniffing/selection maps），排除最终出口选择。
  新增设置沿用协议 v1；旧备份缺这些 maps 时恢复旧默认：8.8.8.8、全局缓存开启、相同出口备用关闭，
  嗅探开启/routeOnly=false/metadataOnly=false，选路轮询；缺省 Fragment 为关闭。
  旧 directDnsAddress 回填主直连 resolver，新捕获只写 dns 规范字段，不维护两份可变地址。
  Smart 的旧 DNS map 忽略单 resolver 超时/缓存覆盖、应答过滤、过期缓存和并发字段，
  后续写出仅包含地址列表、全局缓存和同出口备用设置；其余 resolver 参数沿用 Core 默认值。
  Smart 的旧 sniffing map 忽略 domainsExcluded/ipsExcluded，后续写出仅包含 enabled/routeOnly/metadataOnly。
  常规路由将新参数保存在原 Base64 配置数据，高级/Raw 原文保留；不保存运行观测、探测结果或运行 tag。
  旧常规备份的恢复校验与数据库内部读取兼容剔除废弃 DNS 字段及嗅探排除列表，恢复仍保留 Base64 原文，
  下次编辑保存才写新规范；该兼容入口不放宽外部普通 JSON/分享导入的严格字段边界。
  未知字段容忍不将额外设备选择变成连接参数，旧版本严格解析客户端不保证读取扩展 v1。
  最终出口若是本地节点，仍作为普通节点保存。
- 自定义 Geodata 只保存名称/类型/HTTPS URL，包含待下载声明，省略默认组；不保存任何资源文件。
- `data` 保留数据库 Base64 原字符串，不通过分享格式或普通模型裁剪 Raw/高级内容。
  不保存数据库 ID、收藏、测速缓存、首页选择、专家模式、App 偏好、API 或 Android 自动化授权；
  服务器拨号随当前平台分区保存，显示排序仍为本机设置。
  订阅完整配置与派生行不因活动方式改变而纳入本地资产备份；复制出的个人 Raw 按普通 Raw 保存。

接受上限 64 MiB；检查格式/版本/类型、名称、Base64/UTF-8/JSON 对象及现有资产边界，
不重复实现 Xray 协议校验、不调用 `testXray`、不要求下载成功，也不证明恢复后能运行。
入口完整检查后以私有预览结果传递，预览不重验整份文本；导出检查资产和实际 UTF-8 长度，不重新解码自身产物。

Android 分块限额读取并 finally 关闭句柄，Windows 及 Apple 用户文件分块限额读取。
Apple iCloud 容器手动读取只做一次大小预检并再检查实际字节；插件仍整文件分配，预检不是硬内存上限，
Dart isolate 不能消除插件元数据主线程风险，云占位文件和线程行为须设备核对。

## 恢复与缺失资源

完整读取后先展示资产数、待下载资源与同名冲突，此时不改库、不停 VPN、不下载。
确认后完整替换，不合并；合法空备份会清空连接资产，必须明确提示。

恢复复用清理专用互斥/暂停边界：暂停新操作、等待必要在途任务、取得文件队列、确认 VPN 停止，再提交。
停止失败不替换，DB 与局部 Geodata 日志失败回滚，不自动重启旧 VPN。
新资产生成新 ID，不重置自增序列，旧编辑/回包不能覆盖新资产。
同平台 VPN 设置与连接资产在同一事务中恢复；无匹配分区时保留原平台策略。
保持目标设备的物理网卡、其它平台草稿、偏好、授权和备份设置；恢复为普通模式、自动节点、智能路由，
清空最终出口及 Raw/Custom 当前选择。完成后不自动连接、不立即覆盖云备份，也不追加订阅刷新或测速。

恢复完全离线：默认资源使用当前有效文件或启动准备的内置资源；
只有同名、同类型、同 URL 且有效的自定义文件才复用，其余登记待下载。
预览检查匹配候选，提交前重新核对变化中的冲突和复用事实；只移除本次差异，不清空整个 DAT 目录。
文件发布/恢复和缺库重建见 [数据管理](data-management.md#geodata-发布)。

待下载不阻止首页初始化；依赖它的连接明确报告缺失，不删规则、不改直连、不联网兜底。
用户可用其他配置连接后手动下载，或等待已有的已连接自动更新。订阅只恢复来源与 panel/mode，
完整配置及普通节点通过正常刷新获取，恢复后不承诺提供方缓存可以离线连接；
证书等外部文件需另行准备。Android START 阻断及目标设备授权保留见 [外部接口](external-interfaces.md#设备授权与数据操作)。

## 自动备份

默认开启。绑定空文件自动写入首份备份，有内容时按用户选择恢复或覆盖；首份写入不受自动开关限制。
恢复成功后保持源文件原样，从本次绑定时间起计算后续周期；“本机上次成功写入”仅由实际写入更新。
后续自动备份受开关和周期控制，关闭后仍可手动写入。取消选择不写入；页面加载和备份预览不触发写入。
周期独立保存，默认 3 天，可选 1/3/7 天；仅复用时间选项，不与订阅/Geodata 共用开关、时间或 VPN 条件。
关闭时仍可改周期，修改不立即写，下次正常检查使用新周期。

启动就绪、回前台、每小时、连接成功延迟检查分别判断到期；不等待下载、不要求 VPN、不建立系统后台任务。
进程退出/挂起不承诺准点执行。手动/自动成功都推进本机成功时间，自动失败至少一小时后再尝试，手动不受节流限制。
重复检查不排队；关闭阻止尚未提交的自动写入，提供商已接受的写入允许完成。
目标变更与操作互斥，清理/恢复暂停新操作并等待在途写入；失败只留页面供重试，不弹窗、不抢窗口、不改变 VPN。
页面加载及未到期检查只读取本机偏好，不探测云文件。

## 平台检查

按 [验证边界](validation.md) 使用隔离数据和明确的测试目标，不能覆盖用户已有备份。
签名 Apple 容器/账号、云占位文件与跨设备同步，Android Drive 持久授权/重启/撤权/覆盖，
以及 Windows 三种分发的文件替换/锁/空间故障均需真实环境检查；
Mock、编译和本地文件成功不能替代云端、安装包或 VPN 验收。构建操作见 [构建手册](../build_scripts/README.md)。

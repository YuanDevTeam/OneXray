# 订阅、导入与分享

标准分享用于客户端互通，App Link 与完整 JSON 各有保真边界；备份走 [独立协议](backup.md)，普通导入不猜测备份格式。
导入由显式用户操作提交，系统链接先进入新导入流程。

## 订阅

添加和刷新共用 HTTPS 下载、可选 Age 解密、文本分类、libXray 校验及事务入库。
完整配置逐项校验，跳过无效配置；只有当前使用方式有可用条目才创建或替换。网络、HWID、解密、校验服务异常、零可用或写库失败均保留旧缓存、
套餐、更新时间及输入草稿。报告本轮当前方式实际导入数，不把两类缓存相加，不比较节点 hash 或匹配提供方稳定 ID。
普通节点和完整配置订阅添加、刷新直接提交；Remnawave 非 JSON 响应先确认是否转为普通订阅，
含手工 Raw/Custom/Geodata 的混合导入保留预览确认。

名称、HTTPS URL、Age 成对输入由服务检查；重复 URL 在写入事务中拒绝，下载前快速检查不替代提交复核。
每个来源可选填 `userAgent`，仅覆盖该订阅本次下载的 `User-Agent` 请求头，自定义值优先。
App 下载统一默认使用 `v2rayN/<OneXray 版本> <完整 OneXray UA>`，包括订阅、Geodata 及其它下载；
版本、包名、构建号和平台信息仍来自 OneXray。订阅未填写或清空 UA 时使用同一默认值，不提供全局 UA 选择。
订阅表单默认填入同一兼容 UA，切换面板不清空 UA；手动输入、分享链接及已保存的显式 UA 保留。
已有来源的 UA 为空时，编辑页只补充默认值展示，不自动写入数据库；保存仍需用户明确操作。
添加、编辑和刷新共用此设置，URL 原样请求，不自动附加格式端点。
自定义值须为单行 ASCII 文本；UA 只影响提供方选择的响应，解密、分类及 libXray 校验仍照常执行。
编辑只保存来源设置并使旧请求失效，不下载、不替换缓存或热切换当前运行，也不要求已经有可用缓存。
更新保护准备中、待启动、运行中、固定选择、最终出口及收藏原行，保留它们的 ID 与配置原文，并插入全部新结果；
同名新旧条目允许并存，保护行不计入本轮导入数。保护解除后后续更新清理旧行，不原地覆盖运行配置。
普通活动节点进入自动测速队列，不等待测速；提供方完整配置不进入单 outbound 测速。

### 面板与配置使用方式

来源保存 `panel=generic|remnawave` 和 `mode=appManaged|providerManaged`，分别表示面板标记与活动缓存类型。
旧来源和旧备份缺字段时默认为 `generic/appManaged`。面板标记不替代格式识别；所有来源都先检查解密后的完整 Xray JSON。
Remnawave 在 Age 解密后先判断是否为 JSON：有效 JSON 统一进入完整配置解析，即使只有 `outbounds`；
逐项跳过结构或 libXray 校验失败的配置，无可用配置才报错；有效 JSON 不降级为普通节点解析。
非 JSON 响应由前台操作提示是否转为普通订阅；用户同意后将同一次响应的明文交给 libXray 节点解析，不重新下载。
前台刷新遇到同一来源或整批的在途后台刷新时，补入确认回调，复用当前请求及解析结果；仅后台刷新仍不弹出确认。
解析成功才在保存节点的同一事务中将 `panel/mode` 改为 `generic/appManaged`，保留来源 ID、URL、UA、Age 和 HWID。
取消、普通解析失败或后台无交互上下文时保持来源与缓存原样；确认期间的来源编辑或删除仍使旧更新失效。
仅使用用户输入的 HTTPS URL，不追加 `/json`，不通过 Accept 假定响应格式或替用户开启 HWID。

新来源的“根据订阅格式”是尚未决定的输入状态：普通节点默认 App 管理，完整 JSON 默认提供方模式；
成功导入后保存明确的两种 mode，已有来源刷新保持原 mode；确认从 Remnawave 转为普通订阅时改为 App 管理。
用户也可在添加时明确选择。
一次完整响应同时保存完整配置与可独立表示的普通 outbound 派生缓存；含 `dialerProxy/proxySettings` 依赖的代理
不会删掉引用后伪装成独立节点，系统辅助出站不作为普通节点。

模式切换只改变本地列表与候选类型，不重新下载、解析或生成缓存，不清套餐和更新时间，不自动连接或重连。
当前方式无缓存时提示刷新；固定选择与目标类型不兼容时提示重新选择，不静默改成自动节点。
完整配置可逐项固定选择，也可由原有自动选择策略在普通候选不足时选中，仍不进入最终出口或多接入节点组合。
来源选择只在本来源的活动缓存中寻找目标；不增加提供方来源的专用自动入口。
App 的 Smart/Custom、智能选路和 LAN 共享偏好保留，切回 App 管理节点时继续使用。
删除所选来源最后一个活动服务器时，来源选择回退到自动；活动完整配置可维持这个选择，非活动缓存不能。
删除无关节点不改变因模式切换而暂不可用的原选择，删除整个来源仍清理两类缓存和关联选择。

### 完整 Xray JSON

解密后的单对象或非空数组都可作为完整配置候选，数组每项独立保存为 `CoreConfigType.Remnawave`，关联同一来源。
完整对象先应用 App 入口与系统出站适配，再交给 libXray 校验；数组中的非对象项、无法适配或校验失败的配置逐项跳过，继续处理其它项。
每项按完整配置保留或跳过，不拆删其中的出站、路由或链路来修补配置；全部失败时保留首个校验错误。
不转换 Sing-box 配置；空数组按无配置处理。
Generic 来源仅含 `outbounds` 的普通 JSON 继续旧节点解析路径；有其它根字段的完整候选校验失败不降级为普通节点。
协议、算法等内核语义交给 libXray，不在 App 维护第二套 Core schema。

完整对象不经过普通分享字段投影；outbounds 顺序/tag、链路、routing、DNS、balancers、observatory、mux 及未知扩展字段
保存在同一完整 Map。名称从 remarks/name/来源名加序号取得，存于行元数据，不为名称校验向源对象添加字段。
保存校验在深副本上应用与运行相同的 `RemnawaveAdapter` 和共享 VPN 适配，按需复用或补充入口、系统出站及 DNS 规则，
再使用 Raw 校验投影和串行 `testXray`。本机隧道 DNS 缺省只在运行编译时补齐，不写入订阅缓存。
适配后的配置由 libXray 判断有效性，
列表和选择不再以原始 `outbounds` 是否非空重复拒绝已导入配置，仅保留来源、资产及 JSON 可读取要求；
全部条目处理完后，只提交通过校验的完整配置及其派生节点两类缓存。当前方式无可用条目或校验服务抛出异常时不替换旧缓存。
构造通过不等于 VPN 启动或联网通过，运行托管边界见 [完整配置运行](xray-configuration.md#提供方完整配置)。

查看 JSON 展示保存的原图，不开放普通节点编辑器；需要编辑时复制为个人 Raw，脱离来源更新并计入 Raw 三份配额。
复制和完整配置分享先在深副本应用同一可移植 VPN 适配，再使用现有 Raw 交换及 Geodata 伴随链接；
不固化本机 DNS、TUN FD、运行端口、资源路径或网卡。分享副本用元数据名称补 Raw 名称，数据库原图不改。
敏感信息确认沿用完整配置分享合同；DNS 补充边界见[完整配置的 VPN 适配](xray-configuration.md#完整配置的-vpn-适配)。

### 套餐信息

从同一次响应的 `Subscription-Userinfo` 读取 `upload/download/total` 非负整数字节和 `expire` Unix 秒。
字段名不区分大小写，未知、重复、无效、溢出及不可展示日期分别按未提供处理，不阻断节点导入。
`total=0` 表示无限，`expire=0` 表示无到期，缺失不等于无限；上下行齐全才计算已用，已用及正额度齐全才计算剩余。
超额剩余显示零，已用保留原值；IEC 单位，日期/获取时间使用本地时间。过期或用尽只提示，不限制连接和选节点。

套餐和节点在同一事务提交，获取时间来自响应；成功但无有效信息清除旧缓存，部分信息不拼接旧响应。
仅重命名或改变 panel/mode 保留套餐；URL/Age/HWID/User-Agent 请求设置变化后清空。
panel/mode 变化同样使旧导入失效，迟到响应不得覆盖编辑、切换或删除结果。
列表摘要和分组详情明确“提供方信息、非实时”，无数据隐藏区域，缺字段显示未提供。
套餐不是 App 流量，不增加请求、定时器或周期，不进入分享和备份；恢复后由正常更新重新获取。

### 可选设备标识（HWID）

发送开关默认关闭，由用户明确开启，响应和导入链接不能代为开启；Age 与 HWID 可组合。
标识是每订阅独立的随机 UUID，不读取硬件/广告/系统标识。生成后永久保留于该来源：
关闭再开、改名、改 URL/提供商、失败重试、重启和升级均不重建；删除重建或清理数据才产生新标识。
跨源编辑 URL 时关闭发送开关，用户重新开启仍发送原标识。删除本地来源不删除提供商设备记录。

只在本次请求附加 `x-hwid`，不写共享客户端默认头，不附加型号/系统版本。
HTTPS 同源重定向保留，跨源移除且后续跳回也不恢复；同源按协议/主机/端口判断。
Age 公钥沿用同一下载上下文；HTTPS 降级拒绝。跨源服务须由用户直接配置并授权该 URL。
先检查 HWID 拒绝头再解析正文，HTTP 200 空正文/占位节点不能绕过拒绝；非成功状态也保留具体拒绝原因。
HWID、发送开关不随普通分享发出，也不参与 Xray 配置或 VPN 校验。

## Age 加密订阅

`ageSecretKey` 用于本地解密，`agePublicKey` 经 `X-Age-Public-Key` 发给服务端；
两者同时存在或同时为空，App 不从私钥补公钥、不验证是否匹配。
libXray 生成 X25519 或 ML-KEM-768 + X25519 混合密钥；生成覆盖已有输入需确认，手动编辑保存不触发该确认。

libXray 的 `decodeSubscriptionText` 在内存中解密官方 age armor，未加密输入原样返回。
App 在解密之后区分普通节点与完整配置，不先投影 outbounds；明文即使带私钥也保持原文本。
解密明文上限 16 MiB，区分私钥无效/缺少、解密失败、内容过大；损坏 armor 映射为解密失败。
失败不能以空结果覆盖旧订阅。Age 只保护响应负载，不隐藏订阅 URL、不替代 HTTPS 或证明来源可信。

Age App Link 只携带算法，不带公私钥；接收端生成新密钥对，服务端须能响应新公钥。
[备份](backup.md) 保留完整密钥对且文件未加密，写入前明确提示风险；恢复不重新生成。
日志不得记录私钥、完整密钥对、解密正文或含密钥上下文；不写解密临时文件。
成功导入的完整明文配置与节点凭据属于本机缓存，Age 不为数据库或完整配置导出提供静态加密。
明文限制与 Invoke 请求/响应包裹的独立限额见 [libXray 解码接口](../../libXray/README.md#decodesubscriptiontext)。

## 节点与标准格式

- 支持 VMessAEAD/VLESS 标准链接、Hysteria2（`hysteria2://` / `hy2://`）、SS、SOCKS、Trojan 和 Base64/Age 订阅。
  旧 VMessQrCode（`vmess://Base64(JSON)`）及 Clash/Mihomo 不在范围。
- Hysteria2 支持认证、IPv6、SNI、Salamander、多端口和名称，导出统一 `hysteria2://`；
  禁止跳过 TLS 校验，无法等价转换的 `pinSHA256` 拒绝。字段及导出限制见 [libXray](../../libXray/README.md#parse_share)，
  运行网卡策略见 [配置合同](xray-configuration.md)。
- 标准链接和仅 outbounds 的普通订阅 JSON 经过 libXray 节点解析，可能受到协议/字段白名单投影；
  不能把它称为完整配置或任意 outbound 无损导入。手写节点 JSON 不经普通表单重建；
  完整订阅 JSON 使用上述独立路径，标准格式的接受/拒绝仍由 libXray 决定。
- 名称使用 `tag`；仅键缺失时兼容旧 `name`，无名以协议补齐。`sendThrough` 保留绑定语义，不参与命名。
  KCP seed/header、废弃 `allowInsecure` 不在标准分享内，App 不另校验协议算法或补写规范字段。
- 文件直接使用系统选择器，扫码仅 iOS/Android。失败保留输入，成功 toast 后提交测速，不等待测速完成。

## App Link

外部链接由 `ShareService` 在启动早期暂存并广播；服务初始化不等待导入页面。
主界面服务就绪并渲染后订阅广播、主动读取一次，共用原子领取入口，按到达顺序逐项打开原有导入流程。
Setup 期间只暂存，已有导入或其它模态关闭后再继续。相同 URI 在排队或处理中合并；
完成、取消、失败或页面销毁均结束本次领取，不自动重放，之后用户再次打开同一链接仍可导入。
暂存只在内存中保留；Widget 导航链接仍由独立入口处理。

规范 scheme/host 为 `onexray://onexray.com`：

```text
/config/add?type=outbound|raw|custom|custom-advanced&data=<base64>#<name>
/sub/add?url=<https-url>&age=x25519|hybrid&panel=generic|remnawave&mode=appManaged|providerManaged&userAgent=<encoded-user-agent>#<name>
/dat/add?type=domain|ip&url=<https-url>#<name>
```

解析严格检查 scheme、host、path、类型、重复/未知参数、Base64；订阅和 Geodata URL 只接受 HTTPS。
旧 Profile/full 拒绝，不为退休类型生成链接；类型显式指定，不根据字段猜常规/高级。
订阅链接的 age/panel/mode 可省略：缺 panel 为 generic，缺 mode 由首次响应决定；新生成链接携带保存的 panel/mode。
可选 `userAgent` 保留该来源的显式下载 UA；省略时使用接收端统一的订阅默认 UA，与面板类型无关。
未知或重复参数拒绝，链接不包含 HWID、发送开关或秘密密钥；重复 URL 导入只刷新已有来源，不覆盖它的 panel/mode。
Raw 保留原文语义，高级不经过普通模型；两类 Custom 共用名称唯一和三份上限，详见 [配置合同](xray-configuration.md)。

两类 Custom 完整交换可通过 `geodata.assets` 携带非默认 Geodata 的文件名与 HTTPS 来源 URL，存储前移除该交换元数据。
Raw 保留配置原文，依赖通过独立 `/dat/add` 伴随链接提供。
依赖只扫描 routing、DNS、入站嗅探和 DNS outbound 等语义位置的标准 ext 引用，不扫描凭据或任意字符串。
冲突、下载、确认、发布、回滚统一遵循 [Geodata](data-management.md#geodata-发布)。
分享/导出完整配置前提示敏感信息风险；旧超额 Raw 完整保留。

## 系统分享

`OutgoingShare` 在 iOS/Android/macOS/Windows 使用 `share_plus` 发送已有文本；
Linux 显式复制，不使用邮件回退。标题/主题用显示名称，空名回退 OneXray；链接仍是文本，不改 URI 元数据或临时文件。
分发不下载、不保存资产、不启动 VPN；二维码、JSON、日志和运行配置导出仍为明确文件保存。

页面操作负责局部 loading、防重复提交、Raw/Custom 风险确认和异常反馈；分发前测量按钮位置，无有效位置则省略。
准备期间页面已关闭/隐藏不再弹系统窗口；原生分享开始后不取消，迟到结果不导航、不提示无关页面。
原生 success/dismissed/unavailable 静默完成，不证明送达、不触发 toast、复制回退或重试；
抛异常保留具体原因。Linux 复制成功显示两秒 toast 并留在页面，不增加全局分享队列或轮询。

真实提供方、安装包升级、系统分享与输入法等平台检查遵循 [验证边界](validation.md)；自动测试不代替这些验收。

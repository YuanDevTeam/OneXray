# 验证

以当前源码和[行为合同](README.md)为准。测试验证操作与结果，而不是实现写法；
旧提交的通过记录不代表当前代码通过。全局执行限制见[工程规则](../AGENTS.md#verification)。

## 场景测试

优先复用生产实现，以小型内存数据库、隔离文件、真实本地 HTTP 和可控的原生替身
组织以下场景。替身不代表内核、操作系统或云端已经验收。

| 场景 | 主要结果 |
| --- | --- |
| 启动与恢复 | 服务就绪后首页可用；缺库或默认资源丢失可离线恢复 |
| 导航与浏览 | 六目的地独立保栈，手机五底栏和顶部设置、宽屏文字侧栏与底部设置可达；业务内容单列 |
| 导入与选择 | 普通节点与完整数组入库、活动方式计数、列表 Stream、普通测速与完整配置选择符合类型 |
| 订阅更新 | 双缓存事务更新，保留准备/待启动/运行/固定/收藏原行与来源身份；切换不热重连 |
| 配置与连接 | 普通/高级/Raw/提供方配置的保存、适配、分享与编译；先停止旧连接再启动 |
| 数据操作 | Geodata 发布、备份恢复、自动周期、清理后的重新使用 |
| 外部入口 | 页面、托盘、快捷入口、HTTP 和 Android 广播调用各自生产路径 |

- 每项先覆盖正常操作与最终状态，再保留真实风险：无效用户 JSON、空订阅保旧、
  权限拒绝、停止失败、过期异步结果、事务/文件回滚、鉴权和破坏性操作准入。
- 同一业务结果在负责层完整验证；页面验证点击、导航、loading 和反馈，不复制服务断言。
  协议往返和关键模型单测保留，分层 lint 独立于 App 场景测试。
- 不用源码字符串、私有函数调用次数或固定测试数量代替行为验证。
  删除旧功能测试；人工破坏本地数据等不可达组合不扩展为产品场景矩阵。
- 每个业务 case 应能对应页面、后台任务、系统事件或公开入口，以及该入口实际产生的数据。
  不为覆盖内部防护，手工添加迁移冲突列/索引、改写私有文件或传入生产方不可能生成的参数。
  用户 JSON、分享链接、备份和网络响应属于真实输入；权限、I/O 与事务失败可在实际依赖边界模拟。
  删除不可达 case 不等于删除生产防护，已发布数据库升级与历史数据保留仍需验证。
- UI 保留主题关键尺寸、颜色、安全区、长文案及 RTL 验证，使用代表性尺寸/语言组合，
  不降低高保真标准，也不全面交叉所有状态。
- fixture 仅共享确实重复的数据库、文件和节点样本；不引入通用场景 DSL 或大型测试基类。
  先补齐等价行为覆盖再删除重复测试，不按正负比例或数量衡量完成。

## 界面适配与输入反馈

按[界面合同](app.md)选择代表性窗口、语言和系统字号，不以字号缩小或控件存在代替实际可操作性。

- 代表性手机、平板和桌面窗口分别核对连接/服务器/路由/隧道/Xray/设置六个目的地。
  手机根页保留前五项底栏和顶部设置，设置页及二级页面隐藏底栏；宽屏保留文字侧栏、置底设置和更新提醒。
  手机底栏核对内缩圆角卡片、蓝底白字选中项、五项标签与选中语义；切换保留分支栈，进入详情隐藏、返回恢复。
  短高横屏叠加侧边和底部安全区，所有入口仍可见或可滚动到达；横竖屏往返保留当前详情及各分支导航栈。
  内容始终单列，打开资源、规则或诊断详情不生成右侧工作区。大字和 RTL 选择代表性组合，不重复全部状态矩阵。
  平板与桌面宽布局业务区直接填满侧栏旁的剩余空间，不保留整区圆角裁切、装饰外框或外层留白；
  页面内容边距、单栏、横向安全区、macOS 标题栏和 RTL 原生按钮避让仍须正确。
- 页面标题、返回及页面操作位于共享标准 Flutter AppBar，不固定展示 logo、App 名称或工作区路径，也不在下方添加重复页标题区。
  AppBar 没有主题快捷按钮，主题仍可由设置修改；检查长标题、窄宽度和大字号下返回与主要操作可达。
  平板与桌面宽布局在明暗主题下分别检查 AppBar、`PageActionBar` 与 `Scaffold` 背景一致，
  滚动前后没有额外表面着色或抬升效果；手机 AppBar 沿用 Material 默认表现，业务卡片与弹窗样式保持原合同。
- Welcome、准备配置、隐私和选择子页检查完整页面布局：步骤进度、分组内容和底部提示按单列组织，
  宽屏正文与底部按钮使用相同的 Setup 内容宽度，空余高度分配到区块间距，底部动作独立固定，
  短屏、键盘、大字号及 768 宽 RTL 下不以居中卡片或弹窗承载主流程，操作不随正文滚走。
  隐私需明确同意，配置返回不撤销同意；地区建议不直接入库，跳过、清空和子页取消分别保持原草稿语义。
  Windows/Linux 必选有效网卡，保存失败保留地区与网卡草稿，成功保存后才写完成标记。
  本地准备失败可在页内重试；Setup 不导入节点、不测速、不启动 VPN，系统授权面板仍按平台验证。
- iOS 44×44 pt、Android 48×48 dp 的实际点击区域分别检查，宽横屏仍使用对应平台下限。
  点击小图标外围应触发正确动作且只执行一次；关闭、返回、确认及禁用行为不变，键盘和安全区不遮挡动作。
  入口数量选择器覆盖三项边缘命中、选中/禁用、端点圆角及 RTL，桌面维持紧凑尺寸。
  智能与常规路由检查同级卡片、标题高度，以及规则条件、动作、建议列表和拖拽行的圆角；选中背景不覆盖外框。
  各宽度按直连/拦截、代理、DNS、嗅探、预览保持阅读顺序；规则始终进入独立全宽页，取消不改父稿。
  缩放窗口保留 DNS 焦点、选区与嗅探展开状态，不预留空编辑列。
  小屏最大辅助字号下，资源类别标签保持完整且不覆盖正文，状态和 TUN 值可换行，DNS 输入与底部操作可滚动到达。
- 订阅名称、URL、User-Agent 和 Age 输入在空值/已填/错误/禁用时保留真实可编辑语义名称，
  显示/隐藏密钥不丢角色和值保护。分别记录 Widget Semantics、原生 AX 与实际 VoiceOver 播报，不能相互代替。
  macOS 检查相邻可见标题仍可遍历，不把这项回退当作原生 AXTextField 命名已修复。
- 无效测速 URL、共享端口及订阅字段保留草稿，不产生保存或导入结果；提交定位错误字段，
  提示在 toast 超时后仍可见，修改相关输入后更新。订阅离焦校验不提前标记未操作的字段，
  首次输入尚未离焦时不显示错误，离焦后的错误随继续输入更新或清除。
  远端下载、解密和内核拒绝继续作为表单级失败，不能伪装成本地 URL 格式错误。
- 连接阶段依次覆盖断开、准备、连接、已连接、断开过程及失败；静态 VPN 名称和图标不预告成功，
  文案与状态色随真实阶段变化。明暗主题分别核对正常小字对比度，运行文本在普通及运行背景上均满足 4.5:1。
  智能路由预览正文与多入口提示计算实际颜色、背景及透明度组合，浅深色均达到 4.5:1。
- 连接页检查计划与实际运行分离、Raw/provider 名称及入口/最终出口快照、回退来源与实际目标说明，
  重命名、隐藏缓存或新计划不改写运行身份；未知速率/流量/时长不填假值。空库首屏的导入、恢复和完整配置入口可达。
  目标选择器覆盖三标签、搜索、长列表按需构建、管理返回与取消不提交；来源/节点同数字 ID、Raw/provider 同名不串选。
  三个分类标签在明暗主题下有清晰的实色选中态与可读文字；分类切换和完整配置定义帮助只用于浏览，不提交连接选择。
  重连确认取消保留持久化选择和运行快照；确认前资产被删或来源方式改变时不得按旧列表提交。
- 节点、手动添加、Raw 和高级 JSON 编辑检查编辑器随可用正文宽高伸缩，填满名称、工具与提示之外的剩余区域；
  正常空间不保留固定代码框高度或整页外层滚动。横屏、短屏和键盘下编辑器至少 160 逻辑像素，空间不足时工作区整体可滚动，名称/工具/必要提示仍可到达，保存区固定。
  编辑页 AppBar 仅保留返回与有效页面动作，不另放重复关闭按钮；明暗主题下检查四边和圆角，行号、代码及双向滚动条不遮盖边框。
  节点、Raw 和高级 JSON 全宽编辑覆盖干净/修改/手动还原、关闭/取消/系统返回/Escape、继续/明确放弃、
  重复确认、保存中退出、保存失败、加载期间输入及旧稿保存后的新草稿；光标移动不算修改，名称与原文还原恢复干净。
  旧节点弹窗另覆盖遮罩关闭，全宽页不增加遮罩路径；明确放弃不写库，成功保存不循环提示。
  iOS 干净稿保留原侧滑，未保存或保存中的稿不能经手势绕过退出守卫，不以 Widget 返回替代真机手势验收。
  375×667 最大辅助字号下，中俄确认动作完整显示并可点击；按钮纵排时正文仍可滚动。
- 隧道 DNS 覆盖首错离焦/提交、修正、无关修改、IPv6/DoT 生效开关、逐项修正及原始错误复制。
  聚焦和滚动仅针对当前页仍有效的错误；没有对应字段的子页保留页级诊断，存储失败不伪装成本地字段错误。
  平台策略测试保持 Windows MSIX 的原有 IPv6 特例，不将自动化结果表述为 Windows 设备验收。
- macOS 菜单“设置…”与 ⌘, 检查可见/隐藏/最小化窗口恢复、设置子页及其它分支草稿保留、
  重复命令、无输入焦点模态、Setup/初始化失败和 Shell 销毁后的迟到结果。存在模态仅聚焦，不排队导航。
  弹窗首帧前及窗口恢复期间同样拦截；后台分支弹窗不阻挡当前分支，后台路由变化不覆盖根弹窗状态。
  使用真实布尔偏好关闭启动自动连接，现场始终不启动 VPN、不截图，以菜单/AX/窗口状态和日志记录。
- 搜索清除和零结果重置恢复列表，保留排序、收藏偏好；移动端空列表、空手动组和长列表均可进入来源管理。
  服务器节点/完整配置/订阅三类计数和类型准确；打开资源或来源详情仅浏览，显式“使用”才提交连接选择。
  提供方完整配置在列表与详情均可收藏/取消，旧收藏可见，完整配置收藏筛选与节点筛选独立；Raw 不增加收藏能力。
  普通订阅详情覆盖测速、取消、正在取消及完成恢复；同来源不重复提交，取消不影响其它组请求或 VPN。
  节点测速错误初始折叠，展开后可选择、复制原始诊断，后续成功移除错误，折叠不删除诊断。
  主节点列表在无搜索、无收藏筛选且来源为全部来源或手动添加时可整理位置；订阅过滤下不提供手动整理。
  单个非空手动组直接进入，多个非空组先选择完整范围；空组、单节点组和忙碌组不可选为整理范围。
  名称与延迟排序下均可进入整理，草稿按手动位置加载；保存只调整所选完整组，取消或返回不写入，原显示排序偏好保持不变。
- 独立路由首页分别验证使用、编辑和删除，常规/高级共用配额；一项坏资产不阻断其他模式和资源管理。
  完整图运行时保存普通路由偏好不覆盖当前图或触发无效重连。Smart 地区验证单选替换、重复选择幂等和显式清空，
  候选仅取已安装索引；历史 List 不迁移，选择页投影首项，打开/取消不裁剪原值。
  地区 Done 只改父稿，父页保存才提交，取消不写入；Setup 使用同一地区选择行为。服务器地区筛选/选择范围不恢复。
- VPN 隧道与 Xray 分别进入独立分支，平台权限、能力、MSIX 和移动/桌面入口限制仍由真实平台决定。
  只读诊断刷新保留 phase 与原错误，不启停、不测速、不假报检查通过；无运行输入有空状态，运行 JSON 来自实际 Core 输入。
  SE 不显示日志区，诊断与直接路由也不能绕过日志能力限制；LAN 下次启动生效、本地 API 即时开关和 Token 语义不随页面迁移改变。
- 主题标签在普通、大字和受限空间下正确切换横排或纵排，选中语义与即时保存一致；
  App 图标的标题与当前值不因半宽布局碎裂或丢失，窄布局中的值自然换行。
  自动备份标题不重复，开关保留可访问名称、状态、忙态与禁用条件，周期编辑及 iCloud 主动作不变，
  敏感数据提醒和恢复、覆盖确认继续生效。
- 订阅 User-Agent 始终可见；HWID/Age 高级选项在已有配置或 Age 错误时展开。
  折叠再展开、切换面板、验证失败和取消分别核对草稿与原有保存边界。

## 完整配置与模式边界

以下是当前功能的验证合同，不记录某次构建或设备通过状态；执行结果保存在独立验收材料。

- 在隔离库验证 schema 1–8 升至 9、新安装和重复打开：ID、JSON、Age/HWID、订阅及旧 Raw 保留，
  旧地区列删除、panel/mode 缺省正确，未知选择统一回退，退休 full 不激活。
  旧来源 UA 为空；显式 UA 只覆盖当前订阅请求，添加、刷新、编辑清空、分享及备份往返保持原始 URL，
  不影响其它来源、Geodata 或普通下载请求；所有下载默认统一使用带 OneXray 版本的 v2rayN 前缀及完整 OneXray UA。
  新增及已有空 UA 的编辑表单显示同一默认值，展示与取消不保存；已有或异步输入的自定义值保留，
  切换面板不清空 UA；UA 变更使迟到请求失效，失败保留既有配置。
- Remnawave 的 JSON（含仅 outbounds）进入完整解析；有效 JSON 的结构/内核错误不触发转换。
  非 JSON 先确认，再把同一份 Age 解密明文交给 libXray；新增与刷新成功后原子保存 generic/appManaged，
  取消、无前台确认、普通解析失败及确认期间来源变化均保留旧数据，受保护的运行/选择行继续保留。
- 同一脱敏完整数组含普通 host 与 chain/balancer 图：逐项保存通过校验的完整 Map，名称与原图分离；
  Age 解密先于分类，非对象、无法适配和 Core 拒绝的配置跳过，继续检查后续项；失败配置不产生完整或派生缓存。
  部分成功按当前 mode 正常提交并刷新套餐，全部失败、空结果或 native 校验服务异常保留完整旧缓存及来源信息；
  运行服务异常不能被当作单项无效配置忽略。完整配置不降级为普通节点解析，也不拆删出站来挽救失败的配置图。
- 两种 mode 的活动列表、自动候选、最终出口、批测和计数统一过滤；离线切换不下载、重连或清套餐，
  缺缓存与固定选择不兼容有明确反馈，旧菜单和迟到响应再次复查真实来源/模式。
- 刷新保护 preparing/pending/running profile ID 及固定/最终出口/收藏原行，保留旧 JSON 并插新结果；
  失败、来源删除和请求策略改变不覆盖缓存或套餐。删除来源清理两类缓存且按运行引用停机/重连。
- Raw 与提供方的保存校验、复制/分享和运行使用同一可移植 VPN 适配；高级模板不获得完整配置的 DNS 补充。
  验证已有 TUN 的选取、tag 与入口规则同步、缺少时的新建入口，
  以及显式 53 规则的保留、缺少时复用或新增 DNS 出站并前置有界 DNS 规则。
  覆盖有无内置 DNS、FakeDNS、多个 SOCKS/HTTP 入站及显式嗅探关闭。已有 TUN 的设置和嗅探保留；
  已有 DNS 出站不删除，提供方的条件规则和非 DNS 目标不被 App 改写。源对象不变，其余入站/出站相对顺序、
  原业务规则、链式引用、balancer/observatory 和 domainStrategy 保留；配置有效性交由既有 libXray 流程验证。
  提供方缺少的 direct/block 补齐，已有同 tag 定义保留；缺少或为空的原始 outbounds 经导入验证后可列表展示和选择，
  来源、资产与 JSON 可读取检查仍保留。Raw 只补实际需要的辅助出站；个人 Raw 配额与原图查看不互相混淆。
  源对象不变，重复适配不重复插入；复制/分享只携带可移植结构，不固化本机 DNS、FD、运行端口、路径或网卡。

## 显示排序与服务器拨号

显示顺序验证默认顺序在延迟更新后稳定、名称与延迟顺序的确定性、混合普通节点/完整配置，
以及浏览、分组、筛选、最终出口和托盘的一致性。保存/重启/未知值/清理覆盖本机偏好；
自动接入按成功延迟优先、未测/失败/超时按 ID 排后选取，不等待测速；不能用当前显示顺序替代连接候选。
固定节点与最终出口同样允许未知或失败延迟，排除入口、自引用和无效资产的非测速约束保留；
运行中的 leastPing 仍只观察实际多条完整链，单链退化和高级 direct fallback 例外不变。刷新继续沿用资产替换与保护流程。

手动分组覆盖空组、未分组、创建/重命名/移组、解散保留节点与整组删除；旧库升级保留原顺序。
默认模式共享组序和组内顺序，名称/延迟显示偏好不改写它们；全部手动节点仍是 source:0，文件夹不创建连接范围。
整理草稿保存、取消、返回与重启分别核对；延迟/收藏更新不打断草稿，成员变化使旧草稿保存失败，重新加载后可重试。
空组及组织顺序随备份往返，恢复映射新数据库 ID，旧 v1 恢复为未分组；清理和恢复不遗留旧组。
代表性长列表检查按需构建、首尾拖动、边缘滚动及全宽单列详情；手机长按与桌面鼠标拖动在各自平台验收。

拨号验证旧 JSON 的 AsIs 缺省、策略往返、IPv6 关闭后的有效值与偏好保留、有效变更的确认/取消、
同效或停用配置只保存、备份排除，以及等待连接队列后再次核对配置与重连授权。
配置编译覆盖普通三种模式、代理链/Fragment、XHTTP 有效下载与继承、实际物理域名和字面 IP，
并验证 Raw/高级/提供方配置不被全局拨号覆盖、原节点与业务规则不被改写。
关闭 HE 覆盖导入节点、独立下载与 Fragment 的原有设置，系统默认不新增引导 DNS；
WireGuard 覆盖多 peer、带端口域名与 IPv4/IPv6 字面量、链式出口的本地解析，以及共享 Fragment 的 TCP/UDP 混排。
Fragment 覆盖新默认 FinalMask、旧导入 helper 及高级 Freedom mask 的保存/分享/重开，
验证 1–3 条代理链、最终出口、sockopt 和物理接口不因 mask 改写或丢失；Raw/提供方的旧 fragment/noises 保持原样。
XDrive S3 覆盖 pathStyle 缺省/true/false、域名/IP/带端口 endpoint、域名/IP fronting 及链式入口，
检查实际引导域名与源 Map 保留；逻辑 VLESS 地址不替代存储端点，Raw/高级/提供方继续不受全局拨号覆盖。
bootstrap 精确域名规则需先于业务 DNS/FakeDNS，固定独立直连且截止通用备用；
同名 App 查询也会命中该规则，不能将其断言为只对内核自身的查询生效。
页面验证帮助、策略选择、停用但保留的开关、保存反馈与 macOS SE 可编辑，长文案及 RTL 沿用共享尺寸检查。
JSON 提示分别验证 socket、DNS、routing 和高级模板合同，不把顺序或 Force 拨号值加入 DNS 查询策略。
FinalMask 提示区分 TCP Fragment、UDP mask 和 Freedom owner，未知嵌套对象不串入无关传输字段；
S3 字段、keepalive 和 finalRules 覆盖位置过滤、重复键、布尔值及 IP Geodata 候选，未知字段与凭据原文仍可保留。
原生校验分别覆盖私网/回环/链路本地与 CGNAT/文档/公网地址上的无加密 VLESS/Trojan，
有效 VLESS 自身加密不被误要求 TLS；混合订阅跳过无效项、全部失败报错，不在 Dart 自动修补安全配置。
Geodata 验证保持 App 下载/索引与交换 assets 元数据边界，不启用 Core cron，也不把 Core 调度器限额套到 App 下载。

定向测试位于 `test/service/servers/catalog_test.dart`、`test/service/connect/*dialing*`、
`test/service/advanced/policy_editor_test.dart`、`test/pages/advanced/xray/dialing_test.dart` 和相关页面/托盘测试。
这些测试与 `testXray` 只验证值转换、保存和构造；实际 DNS 路径、双栈可达/黑洞、竞速时延和回退行为
需通过可控 Core 网络环境或对应平台 VPN 验收，编译成功、模拟器表单和 Mock 不替代网络证据。
XDrive 配置通过原生构造不代表 S3/Google Drive 传输已经验收；端到端结果需要受控存储后端与双端 Core 的实际请求收据。

- Android 自动化需普通第三方 UID 的后台启停、冷进程、Token 撤销和清理/恢复阻断，
  至少联调一款真实工具；shell 广播不等于工具联调。
- macOS 桌面 UI 使用 Flutter Debug 验证；VPN、Apple 授权、按需连接、SE 跨容器交接
  和签名包需单独人工验收，不以纯 Dart/Swift 测试替代。
- Windows/Linux 在对应环境验收；Windows 区分 EXE/ZIP 与 MSIX 的启动、退出、权限和数据根。
  Linux 分别覆盖 Wayland 与非 GNOME X11（含无合成器），核对只有系统标题栏和按钮，Flutter 正文不叠加控制栏或虚拟边框。
  用真实指针按下与拖动验证系统标题栏移动、四边及角落缩放和最小尺寸；程序调用移动或设置尺寸不代替输入验收。
  根据系统窗口边界与 Flutter 视口分别核对尺寸，避免将原生标题栏或阴影误判为正文留白。
  连续执行标题栏拖动后立即点击系统最大化按钮；系统未提供该按钮时双击标题栏，首次操作必须响应；
  按键持续按住时拖动不得提前结束。
  检查控制栏最大化/还原、双击、关闭隐藏及重新显示聚焦，缩放和最大化往返后首帧完整且空闲 CPU 恢复稳定；
  准备阶段保持窗口隐藏，不提前破坏后台启动策略。
- Linux 启动验收同时覆盖全新 Setup 和已完成设置的主界面，使用隔离数据且关闭自动连接。
  等待主界面侧栏与连接页就绪后，核对真实桌面上的正文、按钮及再次冷启动；
  页面树存在或已报告首帧不能单独证明正文可见。涉及渲染后端的变更须包含实际图形驱动验证，
  软件渲染结果不能代替 Mesa SVGA3D 等驱动环境的验收。
- 云备份需真实提供商的授权、文件覆盖、重新打开及跨设备恢复；本地写入成功不等于云端同步完成。
- 完成后区分自动测试、模拟器、真机、签名渠道及未测项；测试输入使用脱敏数据，并保留原有数据。
